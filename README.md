# Tacta

Tacta — веб-приложение для ведения массажной практики. Интерфейс на русском, расчёты в фунтах стерлингов.

## Возможности

- Расписание на сегодня и календарь с режимами дня, недели и месяца.
- Записи на массаж с предупреждением о пересечениях и учётом времени на подготовку.
- Карточки клиентов с контактами, аллергиями, противопоказаниями, предпочтениями, заметками и историей масел.
- Разовые сеансы и абонементы 5 + 1. Посещения списываются при завершении сеанса или при подтверждённом списании за неявку.
- Журнал с поиском и фильтрами по статусу. Помесячный отчёт по наличным и переводам.
- Каталог услуг и цен, скачивание и восстановление резервных копий.

## Локальный запуск

Из корня проекта запустите один из вариантов и откройте [Tacta](http://127.0.0.1:4173/).

```sh
npm start
# Или напрямую через Python 3
python3 -m http.server 4173 --bind 127.0.0.1 --directory web
```

Для работы сайта достаточно браузера и статического HTTP-сервера. Для проверок используйте Node.js 24 или новее и команду `npm run check`. Устанавливать пакеты или собирать приложение не требуется.

## Публикация в личном GitHub

1. Добавьте проект в личный репозиторий GitHub. На GitHub Free для Pages подходит публичный репозиторий.
2. В репозитории откройте **Settings → Pages → Build and deployment**, затем выберите **GitHub Actions** как источник.
3. Откройте **Actions → Tacta Web → Run workflow** и выберите основную ветку. Следующие обновления основной ветки запустят публикацию автоматически.
4. Адрес появится в результате задания **Deploy to GitHub Pages**. Для обычного репозитория это `https://<имя-пользователя>.github.io/<имя-репозитория>/`.

Workflow проверяет приложение и отправляет на Pages только содержимое `web/`. Относительные пути и навигация через фрагменты URL позволяют открывать разделы напрямую при размещении в подпапке. [Документация GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)

## Данные

Рабочие данные хранятся в профиле браузера для адреса сайта. GitHub обслуживает файлы приложения, а записи клиентов и оплаты остаются в браузере. Копию можно скачать и восстановить в **Настройки → Данные**. Восстановление заменяет текущие данные. При смене устройства или адреса сайта сначала скачайте резервную копию на старом адресе, затем восстановите её на новом. Файл копии содержит данные клиентов, его следует хранить отдельно от репозитория.

Исходники iPhone-приложения находятся в `Tacta/` и `Tacta.xcodeproj`. Данные SwiftData автоматически в браузер не переносятся.
