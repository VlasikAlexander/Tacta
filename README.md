# Tacta

Tacta — веб-приложение для ведения массажной практики. Интерфейс на русском, расчёты в фунтах стерлингов.

## Возможности

- Расписание на сегодня и календарь с режимами дня, недели и месяца.
- Записи на массаж с предупреждением о пересечениях и учётом времени на подготовку.
- Карточки клиентов с контактами, аллергиями, противопоказаниями, предпочтениями, заметками и историей масел.
- Разовые сеансы и абонементы 5 + 1. Посещения списываются при завершении сеанса или при подтверждённом списании за неявку.
- Журнал с поиском и фильтрами по статусу. Помесячный отчёт по наличным и переводам.
- Каталог услуг и цен, скачивание и восстановление резервных копий.
- Синхронизация через личный Google Drive по желанию.

## Локальный запуск

Из корня проекта запустите один из вариантов и откройте [Tacta](http://127.0.0.1:4173/).

```sh
npm start
# Или напрямую через Python 3
python3 -m http.server 4173 --bind 127.0.0.1 --directory web
```

Для работы сайта достаточно браузера и статического HTTP-сервера. Для проверок используйте Node.js 24 или новее и команду `npm run check`. Устанавливать пакеты или собирать приложение не требуется.

## Публикация в личном GitHub

1. Добавьте проект в личный репозиторий GitHub. На GitHub Free для Pages подходит публичный репозиторий.
2. В репозитории откройте **Settings → Pages → Build and deployment**, затем выберите **GitHub Actions** как источник.
3. Откройте **Actions → Tacta Web → Run workflow** и выберите основную ветку. Следующие обновления основной ветки запустят публикацию автоматически.
4. Адрес появится в результате задания **Deploy to GitHub Pages**. Для обычного репозитория это `https://<имя-пользователя>.github.io/<имя-репозитория>/`.

Workflow проверяет приложение и отправляет на Pages только содержимое `web/`. Относительные пути и навигация через фрагменты URL позволяют открывать разделы напрямую при размещении в подпапке. [Документация GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)

## Google Drive

### Настройка

1. В Google Cloud Console создайте проект и включите **Google Drive API**.
2. В Google Auth Platform настройте **Branding**, в **Audience** выберите **External**, оставьте статус **Testing** и добавьте в **Test users** аккаунт Google владельца данных. В **Data Access** добавьте единственное разрешение `https://www.googleapis.com/auth/drive.appdata`.
3. В **Clients** создайте OAuth Client типа **Web application**. В **Authorized JavaScript origins** укажите адрес сайта без пути, например `https://example.github.io`. Для локальной проверки добавьте `http://localhost` и `http://localhost:4173`, затем открывайте сайт через `localhost`. Поле **Authorized redirect URIs** для всплывающего окна можно оставить пустым.
4. Скопируйте **Client ID**. Для локальной проверки впишите его в `web/drive-config.json` в поле `clientId` или запустите `GOOGLE_DRIVE_CLIENT_ID=... npm run configure:drive`. Для GitHub Actions создайте переменную репозитория `GOOGLE_DRIVE_CLIENT_ID` в **Settings → Secrets and variables → Actions → Variables**. Публичный Client ID попадёт в сборку. Секрет клиента и аккаунт Tacta для этого подключения не требуются.

[Настройка Google Identity Services](https://developers.google.com/identity/oauth2/web/guides/get-google-api-clientid) · [Скрытая папка приложения](https://developers.google.com/workspace/drive/api/guides/appdata)

### Использование

- На устройстве с записями откройте **Настройки → Google Drive → Подключить Google Drive**. Выберите аккаунт владельца. Проверьте адрес и нажмите **Сохранить в Drive сейчас**, затем подтвердите первую выгрузку.
- На другом устройстве откройте тот же сайт, подключите тот же аккаунт, выберите копию и подтвердите **Загрузить выбранную копию**. При замене отличающихся записей Tacta хранит прежнюю версию в разделе **Локальные копии перед заменой**.
- После привязки изменения сначала сохраняются в браузере и через несколько секунд отправляются в Drive, пока доступ активен. Перед закрытием можно нажать **Сохранить в Drive сейчас** и дождаться подтверждения. После перезагрузки страницы или истечения срока доступа подключитесь снова.
- При расхождении версий проверьте список копий. Можно скачать любую версию как JSON, загрузить выбранную в браузер или сделать локальную версию текущей на Drive кнопкой **Сохранить в Drive сейчас**. История копий сохранится. Для возврата к более ранней версии выберите её в списке.
- Чтобы перейти на другой аккаунт, используйте **Выбрать другой аккаунт**. Проверьте показанный адрес перед первой выгрузкой или загрузкой. **Отключить** завершает текущую сессию синхронизации в этой вкладке. Управление выданным приложению доступом остаётся в настройках аккаунта Google.

## Данные

Рабочие записи сохраняются в профиле браузера для адреса сайта. При подключении Google Drive копии содержат клиентов, расписание, услуги, абонементы и оплаты. Они хранятся в скрытой папке приложения в выбранном аккаунте и занимают место на его Google Drive. Токен доступа хранится в памяти открытой страницы. Синхронизация требует подключения к интернету.

В **Настройки → Данные** по-прежнему можно скачать JSON и восстановить данные без Google. Файлы резервных копий содержат клиентские данные. Храните их отдельно от репозитория.

Исходники iPhone-приложения находятся в `Tacta/` и `Tacta.xcodeproj`. Данные SwiftData автоматически в браузер не переносятся.
